для личного некоммерческого использования.

> (автор — **inssekt**, актуальный мейнтейнер — **KansoMirai**), сайт: <https://cocoon-shell.com>.

## Как работает канал

- Приложение читает `updates.json` из этого репозитория (release `manifest`), сверяет
  SHA-256 скачанного APK и ставит его через PackageInstaller.
- Версия в `updates.json` должна быть **строго больше** установленной; `versionCode` растёт.
- Все APK подписаны ключом Cocoon RU (SHA384withRSA). Установка — только после удаления
  официальной сборки; данные переносятся через бэкап Cocoon (System & Advance → Backup).
- Перевод лежит в `values-ru/` этого репозитория — правки приветствуются.
