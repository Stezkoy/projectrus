# projectrus — Cocoon RU

Канал обновлений для русской локализованной версии лаунчера Cocoon (rip.moth.cocoonshell).

- updates.json — манифест, который читает приложение (схема 1)
- APK выложены как assets в разделе Releases
- Все APK подписаны ключом Cocoon RU (SHA384withRSA)
